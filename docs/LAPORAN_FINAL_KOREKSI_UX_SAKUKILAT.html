3. Detail Remediasi dan Fitur per Bagian

3.1 Bagian A — Keselamatan Data & Storage

  • Perlindungan Skema Masa Depan: lib/storage.ts memblokir eksekusi reset pada status incompatible. Unknown keys dari versi skema lebih baru tidak dihapus. UI karantina StorageRecoveryScreen kini menyembunyikan tombol reset destruktif dan memberikan tombol salin/unduh raw JSON.
  • Parser CSV RFC 4180 Ketat: Modul mandiri lib/csv-parser.ts mendukung koma di dalam tanda kutip, escaped quotes, multiline breaks, dan validasi UTF-8. Fallback berbahaya || 10000 dihapus total.
  • Dedup Engine Transaksi Impor: Modul lib/dedup.ts menyaring transaksi ganda berdasarkan signature deterministik (ISO date + type + amount + normalized description + category + subcategory + paymentMethod).
  • Pelaporan Rollback yang Jujur: Sistem memvalidasi status riil eksekusi rollback sebelum menampilkan notifikasi keberhasilan semu.

3.2 Bagian B — Navigasi Sublayer dan Back Stack

  • Modul Navigasi LIFO: lib/back-stack.ts melacak hirarki modal dan sheet yang terbuka.
  • Hardware Back & Popstate: Mengaitkan event hardware back button Capacitor dan browser popstate ke stack LIFO sehingga setiap penekanan tombol kembali menutup sublayer teratas secara berurutan.
  • Isolasi State Parent: Menutup modal tidak mereset state tab induk, nilai filter tanggal, ataupun posisi scroll pengguna.

3.3 Bagian C — Live Rupiah Input

  • Modul Pendukung: lib/amount.ts menyediakan stripToDigits, formatRupiahLive, dan kalkulasi posisi kursor calculateCursorPosition.
  • Komponen <RupiahInput>: Prefix "Rp" terisolasi di luar input teks (tidak dapat terhapus backspace), pemisah ribuan otomatis tanpa loncatan kursor, dan normalisasi paste/shortcuts natural (50rb, 1,5jt).
  • Penggantian Menyeluruh: Digunakan pada tab-saku.tsx, edit-transaction-modal.tsx, goal-tracker.tsx, dan category-manager.tsx.

3.4 Bagian D — UI Pencatatan Transaksi Baru

  • Segmented Type Selector: Tiga tombol segmented lega (tinggi 44px) dengan diferensiasi warna kontras (Pengeluaran merah, Pemasukan hijau, Transfer biru).
  • Amount Hero Section: Area input nominal visual dominan dengan badge − atau +, label dinamis, dan quick chip (+10rb, +50rb, +100rb, +500rb).
  • Pengurutan Kategori Dinamis: Kategori disusun berdasarkan riwayat frekuensi pemakaian pengguna; mengingat kategori terakhir per tipe.
  • Tombol Simpan Adaptif: Menampilkan nominal real-time (cth: Catat Pengeluaran Rp 75.000) serta pencegahan double-submit.

3.5 Bagian E — Fitur Baru: Jejak Kategori Setahun

  • Statistik Engine: lib/stats-category-yearly.ts mengagregasi 12 bulan kalender secara akurat dengan mengecualikan transfer internal dan simpanan tabungan.
  • Visualisasi Explorer: components/category-year-explorer.tsx menyediakan selector tahun/kategori, 5 kartu metrik analitis, grafik batang Recharts 12 bulan interaktif, dan drilldown transaksi bulanan saat batang diklik.
  • Integrasi: Dapat diakses langsung dari tab-rekapan-yearly.tsx dan tab-rekapan.tsx.

3.6 Bagian F — Responsivitas Viewport

  • Proteksi overflow horizontal pada layar sempit (320px+) melalui max-width: 100vw; overflow-x: hidden; pada app/globals.css.
  • Utilitas .scrollbar-none untuk geser chip kategori horizontal tanpa gangguan scrollbar browser.
  • Penyematan safe-area top dan bottom untuk kompatibilitas perangkat mobile modern.

5. Panduan Pengujian Langsung oleh Pengguna

Untuk menguji secara visual melalui peramban:

  1. Jalankan dev server dengan perintah: pnpm dev
  2. Buka http://localhost:3000 di browser Anda.
  3. Input Rupiah: Buka tab Saku, ubah saldo atau limit harian. Coba ketik angka atau shortcut 50rb / 1,5jt.
  4. Form Catat: Klik tombol +. Pilih Pengeluaran / Pemasukan / Transfer. Rasakan hero nominal dan perhatikan kategori teratas berdasarkan frekuensi.
  5. Tombol Kembali (Back): Saat modal terbuka, tekan tombol kembali pada peramban. Modal akan tertutup dengan mulus tanpa me-reload aplikasi.
  6. Jejak Kategori Setahun: Masuk tab Rekapan ➔ Tahunan ➔ Klik Jejak Kategori Setahun. Amati visualisasi batang 12 bulan dan klik salah satu batang untuk melihat daftar transaksi.
